Want it to show which code you wrote?

The wbh command-line tool lets you mark files and blocks with @handwritten comments. It then generates your badge and a report listing every declared line range, linked from the badge.

wbh init
wbh mark src/synth/oscillator.rs
wbh scan

A single offline binary for macOS, Linux and Windows. It never edits your source and never phones home. Get wbh on GitHub

The honest part

Every badge is self-declared. Nobody checks it, nothing detects AI, and code without a badge is just unmarked: it says nothing about how that code was made. It's a celebration of craft, not a verdict on anyone's tools.
